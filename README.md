# OpenRSS

> [!Warning]
> OpenRSS is a beta software that is actively being developed, USE AT YOUR OWN RISK.

This is a project that is built to read through multiple articales and search across all of them, completely locally.

OpenRSS was built on NixOS and is working there, and it has a compiled version for macOS 26 for Apple Silicon, but macOS is still being tested.

## features

Search: Allows search across all cached articales downloaded, by using either keywords like this: security, android, iphone or exact wording like: "zero day", "github has issues"

Sidebar: The sidebar has all the sites on the left and can refresh individually or all at once using the refresh all at the top.

Settings menu: with a settings menu you can clear cached articales or import a opml file or export current.

Reading: In the main window, your articles with fill up the screen. By clicking on OpenRSS will go to the site and parse it into the app itself so you can read it inside OpenRSS without having to do anything else.
